Legend: Shipped = available in product; Deferred = documented later work; Demand-driven = only when beta tenants ask.

EloSync Mobile ​

Native iOS/Android tenant app (Expo SDK 57). Broad module coverage shipped PR-by-PR (CRM, sales, billing, purchasing, HR, Ops, AI, Branded, Storage, etc.). Remaining gaps are module-specific (stats KPIs, trash, some PDF/settings panels remain web-only on mobile v1). See mobile user guide.

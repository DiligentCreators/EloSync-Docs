# Financial Reports — User Guide

1. Enable **Accounting**, then **Financial Reports** from Marketplace.
2. Open **Finance → Financial Reports**.
3. Choose a report:
   - **Trial Balance** — debit/credit nets as of a date
   - **Profit & Loss** — revenue and expenses for a date range, with net income
   - **Balance Sheet** — classic two-pane layout (assets vs liabilities + equity) as of a date, with an Assets = L+E check (includes fiscal YTD net income in equity)
   - **Aged Receivables** — open AR by aging bucket as of a date (historical balance: payments and applied credits on or before that date)
4. Set dates → **Run report**. Amounts use currency formatting and shared report chrome.
5. Use **Export CSV** to download Trial Balance, Profit & Loss, or Balance Sheet.

Reports use posted journals only. Voided journals do not appear.

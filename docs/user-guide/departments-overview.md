# Departments Overview

**Departments** organizes workspace users and employees into teams with a single manager per department.

| Capability | Description |
|------------|-------------|
| Marketplace module | Opt-in under HR (not installed by default) |
| Manager | One user manager per department; one user may manage many departments |
| Membership | Many-to-many for users and employees |
| Performance | Dashboard of Lead/Task metrics for linked users only |
| Visibility | Admins see all; managers see managed departments; staff see memberships |

See the [Departments user guide](/user-guide/departments) for day-to-day usage.
